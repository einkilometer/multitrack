# multitrack

A browser-based audio player for microphone pattern analysis.  
Features solo/mute logic, playhead timer, and visual indicators.


Hosted via GitHub Pages.

https://einkilometer.github.io/multitrack/multitrack_3.html

.

## 🎧 Microphone Comparison Guide

This recording session is designed to highlight the characteristics of different microphones. Each track contains audio captured with a specific microphone.

- **Solo Playback Required**  
  To compare microphones effectively, play soundfiles **one at a time** using the **Solo** button. Avoid simultaneous playback.

- **Jump Buttons**  
  Use the jump buttons to start playback from predefined positions that correspond to specific microphone distances or setups.

- **Recording Setup**  
  Initial recordings were made at approximately **half arm’s length** from the source.

- **How to Listen**  
  Select the microphone you're interested in by clicking its **Solo** button. This isolates the track for focused listening and comparison.
